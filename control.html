Keyboard and mouse

  • Move: W A S D, or the arrow keys (the keys in the same place on other layouts, e.g. Z Q S D on AZERTY)
  • Look: Mouse (click the game view first to capture the pointer)
  • Jump: Space
  • Fire: Left mouse button (hold)
  • Zoom (sniper): Right mouse button
  • Switch weapon: 1 to 4, or the mouse wheel
  • Spore powers (when the meter is full): Q: Mycelium Rush, F: Regrowth, C: Puffball Armour (by key position, so AZERTY uses A, F, C; the HUD shows your own letters)
  • Scoreboard: Hold Tab
  • Pause / menu / back: Escape
  • Skip comics and credits: Hold Space or Escape
  • Next comic panel: Click, Space, Enter or Right arrow

Gamepad

There is no gamepad support for playing. Only the Start button (joystick button 7) is recognised, for skipping comics and credits.
