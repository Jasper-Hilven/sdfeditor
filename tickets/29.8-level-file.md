# 29.8 — The level file `bathroom.level` and its tests

Goal: `content/levels/bathroom.level` fills every section of 29 with the real models (29.2-29.6 supply them; room, fog/steam, machine set, zones and no-fly from 29.1, 29.6, 29.7; the
mover format from 27 is not used) and the tests accept it. Read `content/levels/toybox.level` and `tickets/done/27.9-level-file.md` as the closest example.

Steps:
1. Write the file with every section commented: header with the 30x scale and theme; `play size=(150, 100) noise=0`; `room size=(150, 70, 100) walls=bathroom-wall ceiling=bathroom-ceiling`
   with the light data; `fog density=0.0075 color=#E6EEEA`; the steam emitters; `machines set=bathroom ceiling=...` and the no-fly boxes; `regions base=bathroom-tile` with `grout`
   (if the base material does not draw the grid), `wet`, `puddle`, `suds` (`wobble=0`) as in 29 "Regions"; the zones; the two sides (soap-dish fort `soap-dish0` at (-62, 0) yaw 90 and
   (62, 0) yaw -90, cup keep, the team toothbrushes placed with `y=`, two soap bars inside, flag stand, spawn, pods, turrets, machine zone per 29's tables); the two neutral pods; the
   hand-placed landmarks (each group starting with a comment line = an overlap group: tub, riser, 2 towels, giant duck, 2 pyramids, 2 brushes, scale, drain, window); scatter and trees
   sections (`reach=0`, bands, margins, groups `suds` and `toiletries`: tall section first, knee after) and `draw` groups. Use the models as they exist; check actual sizes against 29's
   tables and adjust positions, not the intent.
2. Tests: `bathroom` in `BattleSidesTests.LevelNames` with its weapons (pistol, blob-gun) and in `MachineLevels` where the toy box is; `ContentBathroom_HasOnlyBathroom` in
   `LevelFileTests` (every named model from `bathroom/`, the pickups, weapons, battle objects or the `bathroom` machine pieces; no material from another theme's folder: none from
   `chess/`, `games/`, `toys/`, `grass/`, `fungi/`, `trees/`, `mushrooms/` other than the players' battle objects) plus `ContentBathroom_SolidModelsHaveColliders`; mirror, clearances and
   lanes as `BattleSidesTests` checks them. When a clearance test fails, change numbers in the file (not the tests), keeping 29's intent, and say so.
3. Bake: `sdf level content/levels/bathroom.level --into Unity/Assets/Level/Generated/bathroom` and report instance counts and baked sizes. Mesh any model not yet meshed (256, 3 LODs).
4. Add the Bathroom entry to anything that lists levels for building (check `LevelBuilder`, `LevelSnapshot`; `CampaignDefinition` already names scene `Bathroom`).

Check: `dotnet build`, `dotnet test`. Acceptance: the bake succeeds, all tests pass, the layout mirrors across x = 0. Dependencies: 29.1-29.7.
