# 12.3 — Re-mesh the ten existing models at 256

Part of [12](12-game-pieces.md). Ten models were meshed at 512; the set must be consistent at 256 (the project's meshing rule).

## Goal

The ten `.glb` files already in `Unity/Assets/Mushrooms/Generated/games/` replaced by 256-cell versions with 3 LODs.

## Files

- Models in `content/models/games/` (`.sdf`): `card-ace-held`, `die-amanita`, `die-d8-webcap`, `die-porcini`, `domino-2-6-side`,
  `domino-5-5-standing`, `domino-6-3-lying`, `domino-chain`, `meeple-fallen`, `meeple-standing`.
- Parts: `die_pips`, `domino_*`, `meeple`, `card_ace`.
- Output: the same names in `Unity/Assets/Mushrooms/Generated/games/` (overwritten).
- This ticket file: fill in the "Result" section.

## Commands

```
dotnet build SDFPipeline.Cli -c Release
for m in card-ace-held die-amanita die-d8-webcap die-porcini domino-2-6-side domino-5-5-standing domino-6-3-lying domino-chain meeple-fallen meeple-standing; do
  /usr/bin/time -p SDFPipeline.Cli/bin/Release/net10.0/sdf mesh content/models/games/$m.sdf \
    Unity/Assets/Mushrooms/Generated/games/$m.glb --resolution 256 --lods 3 2>&1 | tee <scratchpad>/$m.log
done
```

One after the other, 10 minute timeout each (background and wait). Do not touch other models' `.glb` files.

## Acceptance

- All ten files rewritten (clearly smaller than before: `git diff --stat`), 3 LODs.
- Result section: per model the seconds, triangles per LOD, every log warning verbatim; for `die-amanita` the triangles of the
  separate `die_pips` mesh (843k to 22k at 512).
- If `domino-chain` or `card-ace-held` takes over 5 minutes, name the slow phase.
- `dotnet build` and `dotnet test` pass.
