# 29.6 — Bathroom machines: duck tank, spray copter, hairdryer turret, and the copters' no-fly boxes

Goal: the three machine kinds in red and blue as the `bathroom` machine set (27.2: models are `<kind>-<set>-<team>` with kinds turret, tank, helicopter, and parts
`<kind>-<set>-<team>-<part>`; read `Unity/Assets/Battle/Core/MachineSets.cs`, `content/models/machines/` and `tickets/done/27.8-toy-machines.md` for the exact naming and part names
the runtime wants; the level file will say `machines set=bathroom`). 29's table names (`duck-tank` etc.) are descriptions: the files follow the set naming rule, e.g.
`tank-bathroom-red`, `helicopter-bathroom-red`, `turret-bathroom-red` with their parts.

Models, in `content/models/machines/` (same rules, stats and parts as 24 and the toy set, floating scout eyes kept):
- Tank: a rubber duck in team colour riding a sponge tread; head turns (Turret), squirt-nozzle beak is the Barrel; 0.8 m long.
- Helicopter: a trigger spray bottle in team colour, flat rotor spinning on the spray head, tiny fan on the nozzle; 0.8 m tall; parts Body, Rotor, TailRotor.
- Turret: a hairdryer on a coiled-cord foot, the dryer turns, its nozzle is the barrel; 2 m; parts Foot, Head, Barrel.
Team colours red/blue on the machines only; the rest from the bathroom palette (rubber yellow, sponge butter yellow, white plastic). Budgets: tank 5k, copter 4k, turret 6k in
total. Materials in `materials/bathroom/` or `materials/machines/` following the toy set.

No-fly boxes: the bathroom's tub (16.5 m), giant duck and pyramids (9 m) and tall bottles (6.6 m) are in the copters' flight band (6-12 m), so add generic no-fly boxes: pilot rules in
`SdfBattle.Core` (`HelicopterPilot`/`HelicopterLimits` from 27.2) keep helicopters out of boxes and route them around the tub. Level-file driven (the baked `battle` block lists
boxes), or derived from placed collider models whose top is over 5.5 m: your choice, documented in the `LevelFile` header; the level file author in 29.8 will use it. EditMode
tests for the pure rules (never inside a box, goes round, still reaches waypoints). If it does not land cleanly, say so in the Status: the bathroom then ships with tanks and
turrets only and the user decides.

Steps: write models, render and LOOK at each png (is it a duck tank, a spray copter, a hairdryer?), bounds tests, mesh at 256 cells 3 LODs, run `Tools > SDF Machines > Rebuild
Machines` in Unity batch if feasible (see the 27.2/27.8 statuses), the no-fly code and tests.

Check: `dotnet test` (both test projects) and the Unity EditMode tests pass. Acceptance: the `bathroom` set models exist, a throwaway level naming `set=bathroom` builds machine prefabs
for it, the no-fly rules are tested. Dependencies: none.
