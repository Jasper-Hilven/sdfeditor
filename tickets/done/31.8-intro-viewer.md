# 31.8 — The intro viewer

Subticket of [31 — Story intro](31-story-intro.md). Goal: the runtime plays the panels with music, Next and Skip, and ends by loading the first level, with a clean hook for ticket 32.

Steps:
1. `StoryIntro` (runtime, `Unity/Assets/Story/Runtime/`), a screen built by code in `GuiScreens` style or its own scene built by an
   editor script (choose what matches the GUI code; reuse `GuiScreenRoot`, `ToonButton` and `GuiPalette`). Full-screen `RawImage` with
   the current panel, letterboxed to 16:9 on other aspects (bars in ink black); Next bottom right and Skip top right, both about 5 px
   from the screen edges, in the GUI's button style; the last panel's Next reads "Play". Input: Next also on panel click, Space, Enter,
   right arrow; Skip also on Escape and gamepad Start. 0.25 s cross-fade between panels.
2. Music: one looping `AudioSource` on `Assets/Story/Audio/intro-music.ogg` (the user provides it; log one warning and play nothing if
   missing), fade in on panel 1 and out over 1 s on Play or Skip.
3. Panels are loaded as `Texture2D` only when the intro starts (a Resources folder or a ScriptableObject, whichever keeps them
   unloaded until then) and released at the end.
4. Hook for 32: `StoryIntro.Begin(Action onFinished)` (or an event) is the only exit; the default `onFinished` loads the meadow through
   the usual loading. No menu entry is added; 32 wires "Watch intro" and when it plays.
5. EditMode tests for the pure logic (panel index, next/skip, last-panel label, letterbox rect for several aspects).

Check: Unity compiles; tests pass if Unity runs. Dependencies: none hard (build against placeholder images if 31.7 is not done).
