### Adding a level to the campaign

1. Build the scene as `Unity/Assets/Scenes/<Name>.unity` with the name the step already uses (`ToyBox`, `Kitchen`, `Bathroom`, `Computer`, `Boss`),
   a `Match` with the usual red (west) and blue (east) sides, spawns and flag stands, so beats and warm-up find their anchors. Nothing is added
   to the scene for the campaign: `Match` reads the setup the runner passes.
2. Check its row in `CampaignDefinition.Default()` (`Campaign/Core/CampaignDefinition.cs`) against section 2 of ticket 32 (and 33's numbers for
   the boss); a wholly new level is one more `Battle(...)` line plus a `new("beat-<id>", StepKind.Cutscene, "<Scene>", "<title>")` before it.
3. Check or edit its beat in `Beats.Build` (`Campaign/Core/Beat.cs`): actors by name and anchor, shots with a caption and a `CameraMove`. A
   new level adds one `Beat` with the step's id.
4. Optional: a 372 x 196 (16:9) snapshot at `Assets/Campaign/Resources/LevelCards/<Scene>.png` for its Level Select card.
5. Rebuild: `Tools > SDF Campaign > Update Build Scene List` (the release list is written from the steps; an existing scene file is picked up
   by itself, a missing one is left out), then `Tools > SDF Campaign > Rebuild Boot Scene` if the GUI changed. Nothing else: unlocks, `NextStep`,
   Level Select ("Coming soon" until the scene is in the build), Story rows and CONTINUE pick the scene up on their own. Run
   `SdfCampaign.Tests` and `CampaignPlayTest.Run`.
