# 13.1 — Edit the light pieces

Goal: remove the floating eyes and hands from the 10 light chess models, changing nothing else.

Files (`content/models/chess/`): `pawn-light.sdf`, `pawn-light-fallen.sdf`, `rook-light.sdf`, `rook-light-fallen.sdf`,
`knight-light.sdf`, `knight-light-fallen.sdf`, `bishop-light.sdf`, `queen-light.sdf`, `queen-light-fallen.sdf`, `king-light.sdf`.

Steps:
1. In each file delete the comment line "Floating eyes, mirrored, ..." and the two `SymmetryX` blocks below it (one holding
   `Part part=eye`, one holding `Part part=hand`, with their `Translate`/`Rotate`/`Scale`/`Material` children).
2. The body is then the only child of the root `Union`. Keep the `Union` (do not change the nesting or indentation of the body) unless it
   would hold one child only and the format rejects that; if it does, check by building and rendering. Keep `Detail detail=0.5`
   and `collider convex`.
3. Edit the header comment: drop the sentence about floating eyes and hands. In the `Detail` comment, drop "so its eyes and hands get half too".
4. Check that no other eye/hand reference is left: `grep -nE "eye|hand|Eye|Hand" content/models/chess/*-light*.sdf` shows nothing.

Check: `dotnet build SDFPipeline.Cli -c Release`, then `SDFPipeline.Cli/bin/Release/net10.0/sdf render` on two of the files (one
standing, one fallen; see `sdf render --help`) and look at the image: no eyes or hands, rest unchanged. `dotnet test` passes.

Acceptance: the 10 files have no eye/hand text and still parse and render. Dependencies: none (parallel with 13.2).
