# 13.4 — Re-mesh the 19 pieces

Goal: regenerate the chess meshes without eyes and hands.

Commands (from the worktree root; ALWAYS 256 cells, never 512):
```
dotnet build SDFPipeline.Cli -c Release
SDFPipeline.Cli/bin/Release/net10.0/sdf mesh content/models/chess --into Unity/Assets/Mushrooms/Generated/chess --resolution 256 --lods 3
```
Never touch the main checkout.

Steps:
1. Run the mesh; keep the log. It must show no "Part 'eye' ... meshed in place" warnings and no errors.
2. Record LOD0 triangles per piece before (read from the mesher output or the old `.glb`s, which are in git) and after; put the
   rough numbers in the commit message.
3. Commit the regenerated files in `Unity/Assets/Mushrooms/Generated/chess/` (`.glb`, `.meta`, `lifts.json`).

Acceptance: 19 `.glb` files regenerated, one body mesh each, LOD0 smaller than before. Dependencies: 13.1, 13.2.
