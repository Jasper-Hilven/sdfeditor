# 06.1 — Material patterns: `.sdfmat` line, reader, glb extras

Part of [06](06-castles.md) step 5; rules in [06.0](06.0-rules.md). The pipeline half of shader wall patterns: a material file may ask
for a pattern, and the glb says which material has which.

Depends on: nothing.

## Goal

A `.sdfmat` takes one optional line after its parameters, `pattern stones size=0.55 grout=0.035` (kinds `stones`, `fibres`, `gills`;
`size` in metres; `grout` defaults to a twentieth of the size and must be narrower than the size). `MaterialFile.Read` still returns the
same `MaterialDefinition` (the pattern is not a parameter, so the IDE preview and `sdf render` are untouched); a new
`MaterialFile.ReadPattern` returns it. `sdf mesh` / `sdf unity` load the patterns of the materials folder, and the glb's
`extras.sdf.materials[i]` gets `"pattern": {kind, size, grout}` only for materials that have one. A model without patterned materials
bakes to **byte-identical** glb.
