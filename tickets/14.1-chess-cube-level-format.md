# 14.1 — Level format and bake for the room

Goal: the level pipeline can describe and bake the closed cube; the chessboard level is stripped of hills, island edge, foliage and sky.

Steps:
1. Make `hills`, `edge`, `scatter`, `draw foliage` and `sky` optional in the level format if they are not already
   (`SDFPipeline/Levels/LevelFile.cs`, `LevelDefinition.cs`, `LevelBaker.cs`); a level without them bakes the flat floor only, with no
   skirt or underside meshes and no sky data. The meadow's bake output must stay identical (keep or add a test).
2. Add a `room` line, e.g. `room size=(160, 160, 160)` (floor centred on the origin at y=0, four walls standing on the floor's edges,
   ceiling at y=size.y, facing down). The bake writes the room (size, square size 8 m, which squares are dark) into the level's baked
   data so Unity (14.2) can build walls and ceiling. Pattern rule: one checker over the cube's surface; colour alternates across
   every cube edge; floor corners dark. Put the parity in one pure C# function (e.g. `RoomChecker`: face, u, v -> light/dark) and unit test
   it: floor corner dark; squares across the floor-wall edge differ; across each vertical wall-wall edge differ; across each wall-ceiling
   edge differ; i.e. all 12 edges.
3. Edit `content/levels/chessboard.level`: header comment (a closed cube of six chessboards of board-game pieces), remove `hills`, `edge`,
   the `rim` region, both `scatter` blocks, `draw foliage` and `sky preset=dusk`; add the `room` line. Do not touch the `place` block
   or the `light`/`dark` regions.
4. Rebake: `dotnet build SDFPipeline.Cli -c Release`, then `SDFPipeline.Cli/bin/Release/net10.0/sdf level content/levels/chessboard.level --into Unity/Assets/Level/Generated/chessboard`
   (check `sdf level --help`).

Check: `dotnet build` and `dotnet test` pass. Acceptance: the chessboard bake holds only floor, colliders, placements and room data; the
checker parity test passes. Dependencies: none.

the main checkout. Meshing always at 256 cells, 3 LODs, never 512. Each SDF pointer id is one node (reuse only via variables). One
