# 06.2 — Pattern data into the Unity meshes (UV7)

Part of [06](06-castles.md) step 5; rules in [06.0](06.0-rules.md). Carries the glb's pattern to the shader per vertex, without
changing the channels the IDE preview shares.

Depends on: 06.1 (a glb with a `pattern`).

## Goal

`SdfGlb.Material` gets `Pattern` (Vector4: kind 1 stones, 2 fibres, 3 gills; size; grout; weight 1). `MushroomBuilder.Fill` writes
**UV7** (Vector4 per vertex) only on meshes with at least one patterned material: the pattern of the material that weighs most at the
vertex. At the border of a patterned material the weight is 0, so the pattern fades out across the blending faces (an unpatterned vertex
beside a patterned one takes the neighbour's pattern at weight 0, so no faces blend two sizes). Meshes without a pattern have no UV7
and are unchanged. `MushroomStyle` sets `_ToonInk` (`Linear(outlineTone)`). `LevelBuilder`'s mirrored mesh copies must copy channel 7
too (see how it copies channels 2 to 4 in `Mirrored`). Raise `BuilderVersion`.

## Commands

Unity batch `BuildAllInBatch` with a patterned material: temporarily add `pattern stones size=0.5` to a material, mesh one model with
`sdf mesh`, rebuild, check, then revert the temporary change (do not commit it).

## Acceptance

- No compile errors. A mesh of a patterned model has UV7 (check with a small editor script or a log line), one without has none.
- Mirrored copies keep UV7. `dotnet test` passes.
