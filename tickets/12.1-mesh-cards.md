# 12.1 — Mesh the card models at 256

Part of [12](12-game-pieces.md). The cards were the slow ones (`card-house` ran over 30 minutes at 512, see 12).

## Goal

`.glb` files (with 3 LODs) for four card models in `Unity/Assets/Mushrooms/Generated/games/`, each meshed in a bearable time, and
the time, the mesh-log warnings and the triangles recorded.

## Files

- Models: `content/models/games/card-house.sdf`, `card-face-down.sdf`, `card-three-lying.sdf`, `card-king-stuck.sdf`
  (`card-ace-held.sdf` is NOT done here: 12.3 re-meshes it).
- Parts they use: `content/parts/card_ace.sdf`, `card_king.sdf`, `card_three.sdf`.
- Output: `Unity/Assets/Mushrooms/Generated/games/<name>.glb` (and `.glb.meta` files if the folder tracks them; copy the pattern of
  the existing ones).
- This ticket file: fill in the "Result" section at the end.

## Commands

```
dotnet build SDFPipeline.Cli -c Release
for m in card-face-down card-three-lying card-king-stuck card-house; do
  /usr/bin/time -p SDFPipeline.Cli/bin/Release/net10.0/sdf mesh content/models/games/$m.sdf \
    Unity/Assets/Mushrooms/Generated/games/$m.glb --resolution 256 --lods 3 2>&1 | tee <scratchpad>/$m.log
done
```

Run them one after the other, `card-house` last, with a 10 minute timeout per model (run in the background and wait).

## If a model is slow (over about 3 minutes)

Find the slow phase from the log (otherwise time `--lods 1` against `--lods 3`: if only the LODs are slow it is
`QuadricSimplifier`). Fixes, least invasive first, keeping the look: (1) a root `Detail detail=0.3` to `0.5`, below the existing
value, on the big flat models; (2) fewer 2D primitives in the card faces (`card_king` has about 60: drop decorative ones). Re-time
after each change. Do NOT change the mesher's code here.

## Acceptance

- Four `.glb` files exist, non-empty, 3 LODs, meshed at 256.
- Every model took under about 5 minutes alone on the M4 Max; if not, the slow phase is named in the Result section.
- Result section lists per model: seconds, triangles per LOD (from the log), and every warning line of the log verbatim.
- `dotnet build` and `dotnet test` pass.

## Depends on

Nothing. Independent of 12.2 and 12.3 (different files).
